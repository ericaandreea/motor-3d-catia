# motor-3d-catia
3D parametric modeling, assembly, and kinematic motion simulation of an internal combustion engine mechanism using CATIA V5
Project Files

* 'Motor_3D.CATProduct' – Main assembly file (contains all components and mechanical constraints).
* 'Bloc_motor.CATProduct' – Engine block assembly.
* 'Piston.CATPart' – Piston component.
* 'Biela.CATPart' – Connecting rod component.
* 'Manivela.CATPart' – Crankshaft component.
* 'Cilindru.CATPart' – Cylinder guide component.
* 'Alezaj-palier.CATPart' – Bearing support component.

## Key Features
* Full bottom-up 3D assembly using mechanical constraints (Coincidence, Contact, Offsets).
* Kinematic joint planning (Prismatic and Revolute joints) for the slider-crank mechanism.

## How to Open
1. Download all files and keep them in the same folder.
2. Open `Motor_3D.CATProduct` in CATIA V5 to view the complete assembly.
